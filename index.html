Wombat

A fast, native Markdown viewer for your Mac.

Open a file, drop a folder, or paste some Markdown, and read it the way GitHub shows it. Wombat is built with AppKit and TextKit, with no web view and no browser engine inside.

Coming soon. The notarized download isn't published yet.

Download for Mac

Version 0.5.3, a disk image signed and notarized by Apple.

Needs a Mac with Apple silicon and macOS 26 Tahoe or later.

What it does

Reads like GitHub

GitHub Flavored Markdown through cmark-gfm, the parser GitHub itself uses: tables, task lists, footnotes, alerts, emoji, front matter, the HTML READMEs use, and colored code.

Files and folders

Open a folder to get its Markdown files in a sidebar, the table of contents beside the page, links and [[wiki links]] that open in place, and Open Quickly and Find in Files. Documents reload when they change on disk.

Math and diagrams

Formulas are typeset by TeX's rules, and Mermaid flowcharts, sequence diagrams, Gantt charts, mind maps and more are drawn as vector graphics. Nothing is rendered by a web page.

Quick Look

Press Space on a Markdown file in Finder and get a preview drawn by the same renderer as the app.

Export and copy

Export a page as a PDF or as one self-contained HTML file. Rest the pointer on a table, an image or a code block to copy it, and tables paste into spreadsheets as tables.

Private by design

No accounts, no analytics, no tracking. Wombat fetches the images your documents link to and, in the download from this site, checks once a day for a new version. Read the privacy policy.

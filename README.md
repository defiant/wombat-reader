# Wombat

The website and downloads for Wombat, a fast, native Markdown reader for Mac.

- **Website:** <https://defiant.github.io/wombat-reader/>
- **Download:** the newest disk image is under [Releases](https://github.com/defiant/wombat-reader/releases/latest).
- **Contact:** wombat@taga.dev

The pages are published here from the app's own repository, so changes made directly in this one are overwritten.

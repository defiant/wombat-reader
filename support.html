Support

Wombat is a small project, and I'm glad to help.

Get in touch

Write to wombat@taga.dev with a question, a bug, or something Wombat should do. I'll reply as soon as I can.

It helps to include:

  • your macOS version (Apple menu › About This Mac) and Wombat's version (Wombat › About Wombat);
  • what you did, what you expected and what happened instead;
  • for a page that looks wrong, a small Markdown file that shows it. Please make one up rather than sending a private document.

How Wombat treats your data is in the privacy policy: in short, it collects nothing.

Requirements

  • macOS 26 Tahoe or later.
  • A Mac with Apple silicon (M1 or later). Intel Macs aren't supported.
  • An internet connection only for images on the web that your documents link to, and for updates. Everything else works offline.

How do I open a file or a folder?

Choose File › Open… (⌘O) and pick a Markdown file or a folder. You can also drag one onto Wombat's window or its Dock icon, open a file from Finder, or paste Markdown with ⌘V in an empty window or File › New from Clipboard (⌘N).

A folder opens as a workspace: its Markdown files in a sidebar, the file you're reading in the middle and its table of contents beside it. Open Quickly (⇧⌘O) finds a file by a few letters of its name, and Find in Files (⇧⌘F) searches the text of all of them. Documents reload when they change on disk.

How do I make Wombat the default app for Markdown files?

From version 0.5.2 on, choose Wombat › Settings… (⌘,) and click Make Wombat the Default, under Default App. Settings also says which app opens Markdown files now. Wombat becomes the default for every Markdown extension it knows (.md, .markdown, .mdown and the rest), and plain text files stay with the app that opens them.

With Finder, in any version: select a Markdown file (.md), choose File › Get Info (⌘I), pick Wombat under Open with, then click Change All… and confirm. From then on, double-clicking Markdown files opens them in Wombat. The Mac App Store version shows these steps in Settings instead of the button, because the App Sandbox keeps apps from changing the default app themselves.

How does Quick Look work, and why do I see plain text?

Select a Markdown file in Finder and press Space. The preview is drawn by the same renderer as the app, so it looks the same.

If you get plain text instead, open Wombat once so macOS finds its preview extension, then look in System Settings › General › Login Items & Extensions, under Extensions, for Quick Look, and make sure Wombat is switched on. If another Markdown previewer is installed, turn that one off. As a last resort, reset Quick Look by running qlmanage -r and then qlmanage -r cache in Terminal.

Why does Wombat ask for access to a folder?

In the Mac App Store version, apps run in macOS's App Sandbox, which lets an app read only what you've given it. Wombat can read a file you open, but a Markdown file often refers to other files beside it: images, and other notes it links to. When a document needs something in a folder Wombat hasn't been given, it asks you to allow access to that folder. Choose the folder once and Wombat keeps the permission, so it doesn't ask again for the same folder.

The simplest way to avoid the question is to open the folder itself (File › Open…, then choose the folder) instead of a single file. Everything inside it is then available, including images and links between files. Wombat only reads what you give it, never changes your files, and sends nothing anywhere.

In the download from this website, Wombat isn't sandboxed, so there is no such question. macOS may still ask the first time whether Wombat can use files in folders such as Documents, Desktop or Downloads: choose Allow.

Why doesn't an image show?

  • An image on the web needs an internet connection. If it failed to load, Wombat tries again after a little while, or right away with File › Reload (⌘R).
  • An image next to your file is found by the path written in the Markdown, relative to the file, so check the path and the capitalization of the name. In the App Store version it also has to be in a folder Wombat has been given access to: see folder access.

How do I change the text size, font or appearance?

Choose Wombat › Settings… (⌘,) for light or dark, the font, text size, line width and line spacing, which side the table of contents is on, and whether files open in new windows or tabs. ⌘+ and ⌘− zoom, and ⌘0 returns to actual size.

Can I edit a document in Wombat?

No, Wombat is a viewer. Edit the file in any editor you like and Wombat shows the new version as soon as you save. Markdown you pasted into Wombat can be saved as a file with File › Save… (⌘S), and then opened in your editor.

How do I export or copy a page?

File › Export as PDF… and Export as HTML… save the document you're reading, and File › Save… (⌘S) saves Markdown you pasted as a .md file. Edit › Copy as Markdown (⌥⌘C) and Copy as HTML (⌥⇧⌘C) copy what you've selected. Rest the pointer on a table, an image or a code block to show a button that copies all of it, and right-click a table to copy it as CSV.

How do I update Wombat?

The download from this website updates itself, from version 0.5.0 on. Once a day it checks for a new version, downloads it in the background and installs it when you quit Wombat, so the next time you open Wombat it's the new version. To check right away, choose Wombat › Check for Updates…. To stop the daily checks, turn off Check for updates automatically in Wombat › Settings…; the privacy policy says what a check sends.

Version 0.4.0 and earlier can't update themselves. Download the new version from the home page, open the disk image and drag Wombat to Applications, replacing the old one. Your settings, window layouts and reading positions stay, and from then on updates come by themselves.

The Mac App Store version is updated by the App Store, like your other apps from it, and doesn't check for updates itself.
